# Trenchstar icons

Custom beveled vector icons with a shared 64 × 64 canvas, upper-left light, dark extruded edge, and mint detail. Trophy uses a warm gold accent.

Use 24–28 px for menu actions and 40–52 px for section or loading marks. Keep the visible text label; decorative icons have empty alt text and cannot intercept pointer events. Do not replace action labels with icons alone.

The source is `scripts/trenchstar-icons.mjs`. Run it from the web repository with the mobile repository directory as its optional argument to generate identical web SVGs and `components/trenchstar/icons.json`. Native controls use `TrenchstarIcon`; game menus use `icons.js`.
