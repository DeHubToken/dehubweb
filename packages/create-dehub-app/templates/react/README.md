# {{APP_NAME}}

A DeHub mini app with React + Vite and [dehub-sdk](https://www.npmjs.com/package/dehub-sdk).

```bash
npm install
npm run dev
```

1. Replace `YOUR-DOMAIN` in `index.html` and `public/.well-known/dehub.json`.
2. `npm run build` and host `dist/` on https.
3. Sign ownership and submit at https://dehub.io/apps/dev.
4. For sign-in, payments and webhooks on your own server, start from the `server` template (`npx create-dehub-app my-server --template server`).

Docs: https://dehub.io/docs/developers
