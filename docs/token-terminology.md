# Token terminology

Use **tokens** for the DeHub currency in balances, prices, purchases, tips,
rewards and user instructions. Use the existing gold coin for inline amounts
and token artwork. Its accessible label should use the localized token name.

`tokenLabel()` formats display text while preserving other currencies such as
USDC. Keep the original currency symbol in transaction arguments, API fields,
token registries, contract calls, search aliases and stored records.

Documentation should identify **DHB** once when explaining the on-chain ticker.
Keep it in contract references, cashtag examples and historical announcements.
General product instructions and page metadata should say tokens. Update the
docs crawler content and localized SEO table alongside their visible pages.

Creator pricing metadata reads allowances and prices from the shared offer
catalogue, which also supplies the displayed plans and payment policy.
