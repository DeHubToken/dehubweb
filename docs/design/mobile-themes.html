DeHub mobile themes, System

All 11 dehub.io themes, rebuilt as APK screens. The moving backgrounds in these phones are the real background code from dehubweb main, bundled unchanged. Colours, corners and glow were measured on the live site at phone width. The menu icons are the site's own image sets.

Shipped to the APK

  • All eight canvas themes, in Settings with web's names in 110 languages (dehub-mobile #1312)
  • The real backgrounds: web's own code runs in a WebView behind the home feed, paused whenever it is off screen
  • Themed feed card, feed tabs, bottom nav, header and menu sheet, with Jungle grain and War HUD corners and monospace readouts
  • Every other screen takes the theme's page colour

Keep in sync

The theme choice is already saved to the account on web (useSyncedPreference('theme')). If the APK reads the same preference, picking War on your laptop turns the phone to War too. Each background already pauses when it's off screen, which is what saves battery on a phone.
