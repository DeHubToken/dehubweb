# Design mockups

Standalone pages for trying out layouts and themes. The site doesn't serve or build anything in this folder.

- `phone-mockup/phone.html`: one phone screen (feed and menu sheet) styled like dehub.io at phone width, switchable per theme. Its art comes straight from `public/` and `src/assets/`, so it always shows the current icons.
- `mobile-themes.html`: all mobile themes side by side, with how far along each one is.
- `emoji-test/guntest.html`: checks that the custom pistol emoji font renders at large and small sizes.

Open them from a local checkout (e.g. `npx serve .` at the repo root, then browse to `/docs/design/...`).
